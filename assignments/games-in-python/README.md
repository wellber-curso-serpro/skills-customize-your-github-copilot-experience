# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construir uma versão funcional do jogo da Forca para praticar manipulação de strings, estruturas de repetição e condicionais em Python.

## 📝 Tarefas

### 🛠️	Implementar a Lógica Principal do Jogo

#### Descrição
Crie o fluxo principal do jogo da Forca, sorteando uma palavra e controlando o ciclo de tentativas do jogador.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatória a partir de uma lista predefinida.
- Inicializar uma visualização da palavra com sublinhados para letras não descobertas.
- Repetir as jogadas até o jogador vencer ou perder.
- Encerrar o jogo quando a palavra for completamente adivinhada ou quando as tentativas acabarem.


### 🛠️	Validar Palpites e Exibir Progresso

#### Descrição
Implemente a leitura de letras digitadas pelo usuário e atualize o estado do jogo após cada tentativa.

#### Requisitos
O programa concluído deve:

- Aceitar um palpite de letra por rodada.
- Revelar corretamente as letras acertadas na palavra oculta.
- Diminuir o número de tentativas apenas quando houver erro.
- Exibir o progresso atual da palavra e a quantidade de tentativas restantes.
- Mostrar uma mensagem final de vitória ou derrota.
